    ScriptHookV `scrThread` TLS 与纤程调度 ABI 速查
    
          
        
    
        
    
          
    
            
    1. `rage::scrThread` TLS 槽位
    
            
    RAGE 主线程在 TLS（Thread Local Storage）中保存当前活跃脚本线程指针（scrThread::GetActiveThread()，常见偏移 tls + 0x828）。ScriptHookV 在每帧 scrThread::Tick Hook 内切换 TLS 上下文以合法调用 Native。
    
          
    
          
    
            
    2. Windows 纤程协同调度（Fiber Scheduler）
    
            
    ConvertThreadToFiber(nullptr);       // 主游戏线程转为纤程
scriptFiber = CreateFiber(0, ScriptMain, nullptr);
// 每帧 Tick:
if (GetTickCount64() >= wakeAt) SwitchToFiber(scriptFiber);
// 脚本内 WAIT(ms):
wakeAt = GetTickCount64() + ms;
SwitchToFiber(mainFiber);            // 交还控制权给游戏主循环
    
          
    
          
    
            
    3. `scrNativeCallContext` 调用栈布局
    
            
    nativeInit(uint64_t hash);           // 清空 argCount=0，绑定 handler
nativePush64(uint64_t val);          // 压入 8 字节对齐参数槽（float/int/ptr）
uint64_t* nativeCall();              // 触发 NativeHandler(scrNativeCallContext*)，返回结果栈指针
